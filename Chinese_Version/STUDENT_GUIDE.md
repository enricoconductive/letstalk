# 学生指南 - RAG 聊天机器人

## 快速开始（5分钟）

### 第1步：打开笔记本
点击以下链接在 Google Colab 中打开：
```
https://colab.research.google.com/github/enricoconductive/letstalk/blob/main/Chinese_Version/RAG_Chatbot_Chinese.ipynb
```

### 第2步：获取免费 API 令牌
1. 访问 https://huggingface.co 并注册（免费）
2. 访问 https://huggingface.co/settings/tokens
3. 点击 **"Create new token"**（创建新令牌）
4. 选择 **"Fine-grained"** 类型
5. 启用 **"Make calls to Inference Providers"**
6. 复制令牌（以 `hf_` 开头）

### 第3步：运行笔记本
1. 运行**第1步**（安装）- 等待约30秒
2. 运行**第2步**（加载）- 即时完成
3. 运行**第3步**（下载）- 下载您的文档
4. 运行**第4步**（配置）- **先在此粘贴您的令牌！**
5. 运行**第5步**（测试）- 应显示"成功！"
6. 运行**第6-8步** - 等待约2分钟
7. 运行**第9步**（启动）- 复制 `https://xxxxx.gradio.live` 链接

### 第4步：使用聊天机器人
- 在**新的浏览器标签页**中打开 Gradio 链接
- 向聊天机器人提问关于已加载文档的问题
- 每个回答都包含来源引用和相关原文摘录
- **注意：** 机器人仅使用已加载文档中的信息。如果答案不在文档中，它会告诉您。

---

## 示例问题
- 尝试聊天界面中提供的示例问题
- 询问文档涵盖的具体主题
- 提出追问（机器人会记住最近的对话）

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| API 503 错误 | 模型正在加载 - 等待30秒后重试 |
| API 401/403 错误 | 令牌需要 "Inference Providers" 权限 |
| 空回复 | 尝试在第4步中更换其他模型 |
| 超时 | 提出更短或更简单的问题 |
| "找不到信息"的回复 | 答案不在文档中 - 这是正常行为 |

## 需要帮助？
- 检查令牌权限是否正确
- 确保按顺序运行了所有步骤
- 尝试重启运行时：运行时 > 重新启动运行时
